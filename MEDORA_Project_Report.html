1. Project Overview

MEDORA is a next-generation, AI-integrated pharmacy ecosystem designed for quick-commerce compatibility. It connects customers, pharmacies, and delivery agents through a unified platform featuring AI-driven symptom analysis, prescription OCR verification, intelligent medicine recommendations, and real-time order tracking. The system follows a microservices-oriented hybrid monorepo architecture with dedicated frontends for each user role.

4. Module Breakdown

🛒 frontend-user

Customer-facing web app — medicine search, cart, prescription upload with client-side OCR (Tesseract.js), AI symptom chat, order placement & tracking.

🏥 frontend-pharmacy

Pharmacy dashboard — incoming order management, prescription verification with OCR, inventory management, order accept/reject workflows.

🚚 frontend-delivery

Delivery agent panel — view assigned deliveries, update status (picked up → delivered), real-time location tracking.

📱 mobile-user

React Native / Expo mobile app for customers — medicine browsing, prescription upload, order tracking with native UX.

📱 mobile-delivery

React Native / Expo delivery app — delivery assignment queue, GPS-based navigation, delivery status updates.

⚙️ backend

FastAPI core — auth, medicines CRUD/search, orders lifecycle, prescriptions upload/verify, Supabase integration with prototype fallback.

5. AI Services (Microservices)

🩺 Symptom Analyzer

  • Multi-turn AI doctor chat (LLM-powered via OpenRouter / Gemini / OpenAI)
  • Structured medical interview — 5-step diagnostic flow
  • Red-flag detection with critical warnings
  • User allergy cross-referencing from profile
  • Fallback rule-based engine when LLM is unavailable
  • OTC medicine suggestion with disclaimers

📋 Prescription OCR

  • Tesseract-based OCR extraction from prescription images
  • Extracts medicine names, dosages & salt compositions
  • AI validation status: pending → verified → flagged
  • Dual pipeline: server-side (Python) + client-side (Tesseract.js)
  • Pharmacist manual verification layer

💊 Recommendation Engine

  • Generic alternative medicine matching
  • Price-savings calculations (up to 40%+)
  • Confidence scoring for alternatives
  • Salt-composition based matching
  • Integrated via /medicines/{id}/alternatives

10. User Roles & Data Flow

👤 Customer

Search medicines → Upload prescription → AI symptom chat → Place order (pickup/delivery) → Real-time tracking.

🏪 Pharmacist

Receive orders → Verify prescriptions (OCR + manual) → Manage inventory → Accept/reject orders → Dispatch delivery.

🛵 Delivery Agent

View assigned deliveries → Accept assignments → Update status (picked up → in transit → delivered) → GPS tracking.

🔧 Admin

Full system oversight — manage users, pharmacies, medicines reference data, and monitor platform analytics.

11. Datasets & Deployment

📊 Bundled Datasets

  • core_medicines.csv — 2 MB+ medicine reference database (brand, generic, category, pricing)
  • pharmacy_inventory.csv — 1.5 MB sample inventory data
  • users.csv — Sample users with allergy profiles
  • ai_symptom_training.json — Symptom→condition→medicine mapping for AI fallback

🚀 Deployment

  • Web Frontends: Vercel (vercel.json configured)
  • Backend: Any Python host (Railway, Render, EC2)
  • Database: Supabase Cloud (managed PostgreSQL)
  • Mobile: Expo EAS Build (iOS + Android)
  • Local Dev: start_all.bat launches entire stack
